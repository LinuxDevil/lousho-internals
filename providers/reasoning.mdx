---
title: "Reasoning: request to replayed block"
description: "How the `reasoning` option maps to each provider's wire shape, how reasoning chunks flow through streams into events and results, and which blocks are kept on the transcript (Anthropic signed thinking)."
---

`reasoning` (LOU-V13) is one option — `'none'|'minimal'|'low'|'medium'|'high'` or `{ effort?, budgetTokens?, summary?, force? }` — that each provider translates into its own API, and a second half that carries the model's reasoning back: stream chunks → `reasoning.*` events → `result.reasoning`, plus signed blocks kept on assistant tool-call turns for providers that require them back.

## Entry points

- `ReasoningOption` / `ReasoningEffort` / `ReasoningSettings` — `src/providers/reasoning.ts`; surfaced as `createAgent({ reasoning })`, `send(input, { reasoning })`, `ExecuteOptions.reasoning`, `GenerateOptions.reasoning`.
- `reasoningProviderOptions(provider, modelId, option)` — the `providerOptions` for OpenAI/Anthropic/Ollama (same field on `ai` 4.3 and 6/7).
- `openRouterReasoning(modelId, option)` — OpenRouter's unified `reasoning` body field (`{ max_tokens }` with a budget, else `{ effort }`), merged into the request body by `OpenRouterProvider`'s `withRequestChanges` fetch.
- Pi: `reasoningOptions()` in `PiProvider` — effort is a pi `ThinkingLevel`, `budgetTokens` a `thinkingBudgets` entry, gated on the catalog's `reasoning` flag.
- `ReasoningBlock` (`{ text, signature?, redactedData? }`) — `llm.ts`: on `GenerateResult.reasoning`, `StreamChunk.reasoning`, and `Message.reasoning`.
- `streamStep.ts` — `CHUNK_HANDLERS` + `reportReasoning()`: chunks → `reasoning.start`/`.delta`/`.done` events.

## How it works

**Sending.** `resolveReasoning()` normalizes the option (`effort` default `'medium'`), then gates on `REASONING_MODELS` — per-provider regexes of families known to accept it (OpenAI `o1+`/`gpt-5+` minus `-chat`/`o1-mini`/`o1-preview`; Anthropic `claude-3-7`/`…-4+`; OpenRouter's union; Ollama `deepseek-r1`/`qwen3`/`gpt-oss`/`magistral`). `'none'`, an unknown provider, or an unmatched model sends nothing; `force: true` bypasses the gate. `PROVIDER_OPTIONS` then maps to `providerOptions.openai.reasoningEffort` (+ `reasoningSummary: 'auto'` for `summary`), `anthropic.thinking: { type: 'enabled', budgetTokens }` (`THINKING_BUDGETS` 1024/2048/8192/24576, floor 1024 = Anthropic's minimum), `ollama.think: true` (ignored with one warning on `ai` 4). The provider packages add the budget to `max_tokens` and drop `temperature`/`topP` themselves.

**Receiving — streams.** On `ai` 6/7, `reasoning-start`/`-delta`/`-end` parts map to `reasoning-delta`/`reasoning-end` chunks; the open block's `providerMetadata` (Anthropic sends the signature on a delta) is remembered in `ChunkState` and attached at `reasoning-end`. On `ai` 4, `reasoning` parts → deltas, `reasoning-signature`/`redacted-reasoning` → ends. On pi, `thinking_delta`/`thinking_end` events carry `thinkingSignature`/`redacted`. OpenRouter is the special case: the `ai` SDK drops `reasoning`/`reasoning_details`, so `OpenRouterProvider` clones and parses the response body itself (`parseResponseBody`) and injects the observed chunks just before `finish` — only when the SDK reported none.

The wire shapes all converge on two chunk types:

| `StreamChunk` | Carries | Produced from |
|---|---|---|
| `reasoning-delta` | `textDelta` | v4 `reasoning` part, v6/7 `reasoning-delta`, pi `thinking_delta`, OpenRouter `reasoning`/`reasoning_details` text |
| `reasoning-end` | `reasoning?: { signature?`, `redactedData? }` | v4 `reasoning-signature`/`redacted-reasoning`, v6/7 `reasoning-end` (+ held `providerMetadata`), pi `thinking_end`, OpenRouter `reasoning.signature`/`.encrypted` |

**Receiving — events and results.** `generateViaStream()` (`streamStep.ts`) accumulates deltas into `block`/`thought`, emits `reasoning.start` on the first delta and `reasoning.done` (with `tokens` from `finish.usage.reasoningTokens`) when text or a tool call arrives. `reportReasoning()` synthesizes the same start/delta/done for a non-streamed `generate()`. `noteReasoning()` joins each step's blocks into `state.reasoning` → `result.reasoning`; `usage.reasoningTokens` rides the normal usage path (`lousho.usage.reasoning_tokens` on the `chat` span).

**Replaying.** `assistantTurn()` (`agentRunState.ts`) keeps on `Message.reasoning` **only blocks with `signature` or `redactedData`** — Anthropic requires the signed thinking back when a tool-call turn continues. `AnthropicProvider.replaysReasoning = true` makes `toCoreMessages` emit them first in that turn (`toReasoningPart`); pi does the same via `reasoningToPi`. They survive checkpoints and resumes because they live on the saved message. Unsigned reasoning and the reasoning of a final reply are never kept in `messages`.

Downstream consumers all read the same events: `reduceAgentEvents()` stores them on `UIMessage.reasoning`, `toUIMessageStream()` emits `reasoning-start`/`-delta`/`-end` parts for `useChat`, `lousho acp` sends `agent_thought_chunk`, `lousho chat` prints them dimmed, and `recordReplay` cassettes keep the chunks so replay reproduces them.

## Design decisions

- **Known-family gate, `force` escape hatch.** Sending unknown options to a non-reasoning model fails the call; the regexes are checked against the provider packages' sources and `force` covers fine-tunes and new families.
- **Reasoning is not transcript text.** It reports through events/results and `Message.reasoning` for the one provider that needs it back — never concatenated into `content`, so it can't leak into prompts or compaction as prose.
- **Two acquisition paths, one chunk type.** Whether the SDK reports parts or OpenRouter's raw body is scraped, consumers see the same `reasoning-delta`/`reasoning-end` chunks — `result.reasoning`, ACP `agent_thought_chunk`, `lousho chat` dimming and cassettes all hang off that.
- **`reasoning-done` tokens come from usage, not a block field** — token counts arrive at `finish`, after the last block closed.

## Example

```ts
const agent = createAgent({ model: 'anthropic/claude-sonnet-4-5', reasoning: 'medium' });
for await (const event of agent.stream('Prove it.')) {
  if (event.type === 'reasoning.delta') process.stdout.write(event.text);
  if (event.type === 'reasoning.done') console.log(`${event.tokens} reasoning tokens`);
}
const result = await agent.send('Harder.', { reasoning: { effort: 'high', budgetTokens: 16_000 } });
result.reasoning; // the run's reasoning text
result.usage.reasoningTokens;
```
